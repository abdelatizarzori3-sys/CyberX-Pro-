# CyberX Pro — خارطة التنفيذ

## الحالة الآن

الفرع الحالي يقدم MVP محليًا بـFastAPI وSQLite وواجهة عربية بسيطة. يشمل حسابًا ومؤسسة أولية، الأصول، التفويض، تسجيل طلب تقييم محلي غير تنفيذي، وسجل تدقيق. أضيفت في هذا التحديث اختبارات أساسية، فحص جاهزية قاعدة البيانات، رؤوس حماية للمتصفح، عرض التفويضات وإلغاؤها من الواجهة، وسير CI. لا يُعد المشروع جاهزًا للإنتاج.

## المرحلة التالية — أساس SaaS آمن

- PostgreSQL وAlembic وإدارة إعدادات لكل بيئة.
- عضويات مؤسسات وأدوار وصلاحيات ومراجعة MFA.
- اختبارات عزل متعددة المستأجرين على جميع نقاط API.
- ترقيم صفحات ومرشحات لسجلات الأصول والتفويضات والتدقيق.
- سياسة احتفاظ وحذف بيانات، وإجراءات نسخ واستعادة موثقة.

**بوابة قبول:** لا يستطيع مستخدم قراءة أو تغيير بيانات مؤسسة أخرى؛ نجاح اختبارات الهجرة والاستعادة؛ مراجعة مستقلة لمسارات الهوية والتفويض.

## المرحلة الثانية — إدارة النتائج والتقارير

- نموذج findings يربط المصدر والأصل والوقت والثقة.
- تعيين المعالجة والمالك وSLA وإعادة التحقق.
- تصدير تقارير آمن مع صلاحية تنزيل وتدقيق.

**بوابة قبول:** لا توجد نتائج غير منسوبة لمصدر؛ تطابق التقرير البيانات المعروضة؛ لا تتسرب بيانات عبر روابط عامة.

## المرحلة الثالثة — تشغيل تجريبي منضبط

- طابور مهام وعامل معزول، مع تنفيذ معطل افتراضيًا.
- إعادة التحقق من التفويض والنطاق قبل أي تنفيذ؛ قيود موارد واتصال؛ إلغاء فوري.
- لا يضاف أي فحص فعلي إلا بعد مراجعة منفصلة واختبارات نطاق وأثر.

**بوابة قبول:** اختبار منع التشغيل عند انتهاء/إلغاء التفويض؛ اختبار الإيقاف والحدود؛ مراجعة أمنية مكتوبة وموافقة تشغيل.

## المرحلة الرابعة — الدفاع والذكاء الاصطناعي

- إدارة حوادث ومؤشرات استخباراتية ومصادر موثوقة.
- أدلة رقمية مع hash وسلسلة حيازة وتخزين آمن.
- مساعد AI استشاري فقط، بلا صلاحية تشغيل أو تعديل أدلة أو التفويض.

**بوابة قبول:** موافقات وصول وتدقيق؛ تحقق سلامة الأدلة؛ تقييم جودة وتحيز AI؛ خيار إيقاف لكل مؤسسة.

## المرحلة الخامسة — الجاهزية التجارية والإطلاق

- مراجعة الخصوصية والمتطلبات القانونية في الأسواق المستهدفة.
- SSO/متطلبات Enterprise والفوترة والإشعارات حسب الحاجة.
- Flutter بعد استقرار API والويب.
- مراقبة SLO، نسخ واستعادة، استجابة للحوادث، خطة رجوع إصدار.

**بوابة قبول:** لا ثغرات حرجة/عالية مفتوحة؛ استعادة مجربة؛ خطة دعم واحتفاظ وحذف؛ موافقة المنتج والأمن والتشغيل.

## تعريف الاكتمال

كل إصدار له نطاق محدد، اختبارات ومعايير قبول، مالك تشغيل، وسجل قرار إطلاق. وجود صفحة أو endpoint وحده لا يكفي. لا يعتبر أي فحص منفذًا لمجرد وجود سجل task؛ الحالة الحالية `RECORDED` تعني التسجيل المحلي فقط.
